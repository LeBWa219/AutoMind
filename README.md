# AutoMind

Интеллектуальная информационно-аналитическая система управления транспортными
перевозками (демонстрационный MVP): мониторинг автопарка, экономика перевозок
и AI-помощник диспетчера.

## 🚀 Быстрый старт — поднять весь продукт одной командой

**Единственное требование:** [Docker Desktop](https://www.docker.com/products/docker-desktop/) (JDK и Node на комп не нужны — всё в образах).

```bash
git clone https://github.com/LeBWa219/AutoMind.git
cd AutoMind

docker compose up --build
```

Через пару минут откройте **http://localhost:8080** и войдите с кодом доступа
**DEMO-2026**.

Что произойдёт при этой команде: соберутся три контейнера — PostgreSQL
(с автоматическим применением всех миграций и тестовых данных), backend
(Spring Boot) и frontend (nginx). Ключ Яндекс Карт уже в репозитории — карта
откроется у всех одинаково, с дорожными маршрутами.

Полезное:

- остановить: `docker compose down` (данные БД сохраняются в volume);
- полный сброс: `docker compose down -v` (база создастся заново при следующем запуске);
- логи backend: `docker logs automind-backend`;
- отладка API напрямую: http://localhost:8081/api/... (frontend проксирует /api и /ws сам).

## Возможности

| Модуль | Что умеет |
|---|---|
| **Мониторинг транспорта** | Яндекс Карты / OSM-фолбэк, реальные дорожные маршруты (OSRM, «как в навигаторе»), иконки транспорта по типу ТС (фура/грузовик/фургон), зум к маршруту выбранной машины, телеметрия через WebSocket (симулятор на backend), CRUD автомобилей и водителей, история рейсов, ДТП и штрафов |
| **Экономика перевозок** | Заказы с валидацией «пустое ≠ 0», расчёт себестоимости на `BigDecimal` (формулы ТЗ 5.5), прогноз по истории 10 рейсов водителя, ранжирование кандидатов (отсев + веса из БД), назначение водителя |
| **AI Logistics Copilot** | Чат-помощник: объясняет себестоимость, разницу между водителями, риски и рекомендации строго по данным расчёта (заглушка с архитектурой под LLM) |

Интерфейс адаптивный: на десктопе — три панели, на телефоне — режим навигатора
(карта на весь экран + нижняя шторка со списком и информацией, бургер-меню).

## Соответствие законодательству РФ

Реализовано в продукте:

- **152-ФЗ «О персональных данных»**: Политика в отношении обработки персональных
  данных и Пользовательское соглашение встроены в интерфейس (страница входа и главная),
  баннер согласия на обработку cookie, код доступа хранится только в виде BCrypt-хеша.
- **Локализация данных (ч. 5 ст. 18 № 152-ФЗ)**: при развёртывании БД размещается
  на серверах в РФ (в демо-режиме — локальный компьютер).
- **149-ФЗ «Об информации»**: оператор и контакты указаны в Политике, ограничение
  ответственности — в Пользовательском соглашении.

Организационные шаги при выходе из демо-режима (за командой/юрлицом, не код):

- подать уведомление в Роскомнадзор об обработке персональных данных;
- заполнить плейсхолдеры реквизитов оператора в Политике (файл
  `frontend/src/components/legal/Legal.tsx`);
- заключить договоры/оферту с заказчиками и согласовать тексты с юристом;
- при публичном запуске — хостинг и БД в РФ, учёт требований о маркировке
  рекламы и прочих применимых норм.

⚠ Тексты в интерфейсе — рабочие шаблоны, а не юридическая консультация.

## Технологии и структура

- **Frontend:** React 19 + TypeScript, Vite, Tailwind CSS 4, Яндекс Карты / Leaflet, WebSocket
- **Backend:** Java 21, Spring Boot 4, Spring Security, Spring Data JPA (Hibernate)
- **БД:** PostgreSQL 16 + Flyway (7 миграций)
- **Развёртывание:** Docker Compose — postgres + backend + frontend (nginx)
- **Тесты:** JUnit 5 — модульные тесты формул расчёта (`EconomyCalculatorTest`)

```
AutoMind/
  backend/            Spring Boot: com.automind.{auth, fleet, trip, telemetry,
                      economy, order, assistant, common, config}
    src/main/resources/db/migration/   Flyway V1–V7
    Dockerfile
  frontend/           React + TS: pages, api-клиенты, компоненты
    Dockerfile + nginx.conf            статика + прокси /api и /ws
  docker-compose.yml  postgres + backend + frontend
  docs/               проектные документы
```

## Запуск в режиме разработки (для правок кода)

Нужны установленные JDK 21 и Node 18+ (либо используйте docker-вариант выше):

```bash
docker compose up -d postgres     # только база

cd backend && ./mvnw spring-boot:run    # backend на 8080
cd frontend && npm install && npm run dev   # frontend на 5173
```

Тесты backend: `cd backend && ./mvnw test`.

## Ключ Яндекс Карт и безопасность

Ключ JS API (`frontend/.env`, `frontend/.env.production`) добавлен в
репозиторий намеренно: JS-ключ по своей природе публичный (он виден в браузере
у любого пользователя сайта), а репозиторий приватный. При выходе в публичный
доступ добавьте в консоли Яндекса ограничение по HTTP-referrer и при
необходимости ротируйте ключ. Построение маршрутов выполняет бесплатный OSRM
(данные OpenStreetMap) — ключ Яндекса для этого не используется.

## Демо-сценарий (ТЗ 12.6)

Войти → «Мониторинг» → выбрать автомобиль → водитель, телеметрия, поездки, ДТП →
«Экономика перевозок» → «Создать заказ» → заполнить и «Рассчитать себестоимость» →
сравнительная таблица кандидатов с рисками и обоснованием оценки → «AI Copilot» →
спросить «Кого лучше отправить?» → назначить водителя. Данные для демонстрации
кейса «дешевле ≠ лучше» зашиты в миграцию V7 (экономичный водитель с ДТП,
чистая история, повышенный расход и т. д.).

Проектные решения по недочётам ТЗ: [docs/PROJECT_DECISIONS.md](docs/PROJECT_DECISIONS.md).
