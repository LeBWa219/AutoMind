# Генератор макета AutoMind для Figma

Плагин создаёт страницу **«AutoMind · Макет»** с дизайн-системой и 9 экранами
приложения (десктоп, 1440 px) строго в палитре ТЗ раздела 2. Все фреймы —
нативные, редактируемые (auto-layout).

## Как запустить

1. Откройте Figma и создайте любой файл дизайна (или откройте существующий).
2. Меню **Figma (☰) → Plugins → Development → Import plugin from manifest…**
3. Выберите файл `figma-plugin/manifest.json` из этого репозитория.
4. Меню **Figma (☰) → Plugins → Development → AutoMind Mockup Generator** — запуск.
5. Через пару секунд появится страница «AutoMind · Макет» с 10 фреймами.

Повторный запуск пересоздаёт страницу заново (старая удаляется), так что любые
правки `code.js` можно сразу смотреть в Figma.

## Что генерируется

| № | Фрейм | Содержание |
|---|---|---|
| 01 | Дизайн-система | палитра 2.2, состояния 2.3, типографика, кнопки, поля, бейджи |
| 02 | Вход | форма входа по коду доступа (ТЗ разд. 3) |
| 03 | Главная | три функциональных блока + KPI + топбар (ТЗ 2.5) |
| 04 | Мониторинг транспорта | боковая панель, карта с маркерами/маршрутом/легендой, правая панель: водитель, авто, телеметрия, 3 поездки, ДТП и штрафы (ТЗ разд. 4) |
| 05 | Список заказов | таблица заказов со статусами (ТЗ 5.2) |
| 06 | Создание заказа | три секции формы, ошибка валидации, чек-лист проверки (ТЗ 5.3–5.4) |
| 07 | Результаты расчёта | KPI, сравнительная таблица кандидатов с выделением лучшего, обоснование оценки, назначение (ТЗ 5.7–5.10) |
| 08 | AI Logistics Copilot | чат с рекомендацией, индикатор обработки, чипсы промптов, контекст заказа (ТЗ разд. 6) |
| 09 | Добавление автомобиля | модальная форма с проверкой уникальности VIN (ТЗ 4.4) |
| 10 | Добавление водителя | модальная форма (ТЗ 4.5) |

## Smoke-тест в Node (без Figma)

```bash
node tools/test-figma-plugin.js
```

Подменяет Plugin API моком и проверяет, что генератор создаёт 10 корневых
фреймов без исключений.
